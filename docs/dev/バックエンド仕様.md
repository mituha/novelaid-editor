# バックエンド仕様

## 概要
本アプリケーションのバックエンドは Electron のメインプロセスによって構成されています。
ファイルシステム操作、AI 連携、Git 操作、テキスト解析などの重量な処理やシステムリソースへのアクセスを担当し、レンダラープロセス（フロントエンド）とは IPC (Inter-Process Communication) を介して通信します。

## 主要コンポーネント

### 1. FileService (`src/main/fs/FileService.ts`)
ファイルおよびディレクトリの基本的な CRUD 操作と、ドキュメントタイプの管理を担当します。

*   **ドキュメントタイプ判定**: 拡張子および `.novelaidattributes` ファイルの設定に基づき、ファイルの種類（`novel`, `markdown`, `chat`, `image`, `css`, `unknown`）を判定します。
*   **属性制御**: ディレクトリ内の `.novelaidattributes` に記述されたパターン（例: `*.md novel`）により、デフォルトの判定を上書きできます。
*   **タイプ継承**: ディレクトリの用途（優先ドキュメントタイプ）は、名前のキーワード（例: `novel`, `チャット`）や親ディレクトリの設定から継承されます。
*   **新規作成**: `createUntitledDocument` は現在のディレクトリタイプに応じた適切なファイル名（「新規小説.txt」など）でファイルを作成します。

### 2. MetadataService (`src/main/metadataService.ts`)
プロジェクト内のファイルのインデックス化と検索機能を提供します。

*   **プロジェクトスキャン**: ルートディレクトリ以下のファイルを走査し、メタデータ（プロパティ、タグなど）をメモリインデックスに保持します。
*   **タグ検索**: `queryByTag` により、特定のタグを持つドキュメントを高速に検索できます。
*   **除外設定**: `.novelaidignore` に記述されたパターンに一致するファイルはインデックスおよびファイル一覧から除外されます。
*   **ファイル監視**: `FileWatcher` と連携し、ファイルの追加・削除・変更をリアルタイムでインデックスに反映します。

### 3. AIService (`src/main/ai/AIService.ts`)
AI モデルを利用したテキスト生成とチャット機能を提供します。

*   **マルチプロバイダー**: LM Studio (ローカル), Google Gemini, OpenAI の各 API をサポートしています。
*   **ストリーミングチャット**: 長文生成時にレスポンスを順次フロントエンドへ送信します。
*   **ペルソナシステム**: キャラクター設定ファイル（メタデータ内）やプリセットに基づき、AI の振る舞いを動的に変更します。
*   **ツール利用 (Function Calling)**: AI が必要に応じてプロジェクト内のドキュメントを検索したり読み込んだりすることを可能にします。

### 4. CalibrationService (`src/main/calibration/CalibrationService.ts`)
執筆支援のためのテキスト解析および校正機能を提供します。

*   **形態素解析**: `kuromoji.js` を使用して日本語の形態素解析を行い、頻出単語の抽出や品詞の判定を行います。
*   **漢字の閉じ開きチェック**: 「事」→「こと」などの、漢字で書くかひらがなで書くかの表記揺れをチェックします。
    *   カスタムルールは `.novelaid/kanji-rules.txt` で定義可能です。
*   **textlint 連携**: `no-dropping-the-ra`（ら抜き言葉）、`no-doubled-joshi`（助詞の連続）、`ja-spacing`（空白ルール）などの校正ルールを適用します。

### 5. GitService (`src/main/git/GitService.ts`)
プロジェクトのバージョン管理のための Git 操作を提供します。

*   **基本操作**: `init`, `status`, `add`, `commit`, `log`, `diff`, `push` などのコマンドをサポートしています。

### 6. StorageService (`src/main/storage/StorageService.ts`)
設定情報の永続化を担当します。

*   **グローバル設定**: アプリケーション全体の設定（最後に開いたプロジェクトなど）。
*   **ローカル設定**: プロジェクトごとの個別設定。
*   データはユーザーデータディレクトリ内の JSON ファイルとして保存されます。

## IPC インターフェース

フロントエンドからは `window.electron` を通じてバックエンドの機能を利用します。
主なチャネル定義は `src/main/preload.ts` で確認できます。

*   `fs:*`: ファイルシステム関連
*   `metadata:*`: メタデータ・検索関連
*   `ai:*`: AI 関連
*   `git:*`: Git 関連
*   `calibration:*`: 解析・校正関連
*   `project:*` / `storage:*`: プロジェクト管理・設定関連

### ファイルシステム系 (`fs`)
| チャネル | 引数 | 戻り値 | 説明 |
| :--- | :--- | :--- | :--- |
| `fs:readDirectory` | `dirPath: string` | `Promise<Dirent[]>` | ディレクトリ内容の読み取り。 |
| `fs:getDirectoryType` | `dirPath: string` | `Promise<DocumentType>` | ディレクトリの優先ドキュメントタイプを取得。 |
| `fs:getDocumentType` | `filePath: string` | `Promise<DocumentType>` | ファイルのドキュメントタイプを取得。 |
| `fs:readFile` | `filePath: string` | `Promise<string>` | テキストファイルの読み取り。 |
| `fs:writeFile` | `filePath: string, content: string` | `Promise<void>` | テキストファイルの保存。 |
| `fs:readDocument` | `filePath: string` | `Promise<any>` | メタデータを含むドキュメントの読み取り。 |
| `fs:saveDocument` | `filePath: string, data: any` | `Promise<void>` | メタデータを含むドキュメントの保存。 |
| `fs:createFile` | `filePath: string` | `Promise<boolean>` | 空ファイルの作成。 |
| `fs:createUntitledDocument` | `dirPath: string` | `Promise<string>` | 未命名ドキュメントの自動生成・保存。 |
| `fs:createDirectory` | `dirPath: string` | `Promise<boolean>` | ディレクトリの作成。 |
| `fs:rename` | `oldPath: string, newPath: string` | `Promise<boolean>` | ファイル・ディレクトリのリネーム。 |
| `fs:move` | `oldPath: string, newPath: string` | `Promise<boolean>` | 移動（競合時はダイアログ表示）。 |
| `fs:copy` | `srcPath: string, destPath: string` | `Promise<boolean>` | コピー（競合時はダイアログ表示）。 |
| `fs:delete` | `targetPath: string` | `Promise<boolean>` | 削除。 |

## 特殊ファイルとディレクトリ

*   `.novelaid/`: プロジェクト固有の設定やキャッシュを保持するディレクトリ。
    *   `kanji-rules.txt`: 漢字の開きルールのカスタマイズ。
*   `.novelaidattributes`: ファイルやディレクトリの属性（ドキュメントタイプなど）を定義するファイル。
*   `.novelaidignore`: スキャンや一覧表示から除外するファイルを指定するファイル。
