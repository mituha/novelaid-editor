開発環境に関連するメモ



## package.json のバージョン

```
npm i --package-lock-only
```
でバージョンのみ適用できる。

```
npm version 0.40.2
```
で、バージョンの設定とlockへの適用ができる。
こっちの方が早い
バージョン指定せずに`patch`とかの指定で自動インクリメント。

```
npm pkg get version
"0.40.2"
```

自動でインクリメントするための`bump-version.psq`を追加。
呼び出すだけで、patch部分をインクリメントします。
引数で、`patch`、`minor`、`major`を指定できます。

## `npm i` でエラーが出た

electron-builderに起因してpostinstallでエラーが出た。

```
Unable to find electron's version number, either install it or specify an explicit version
```

https://github.com/electron-userland/electron-builder/issues/9143
electron-builderのバグっぽい。
ルートとrelease/appの両方にpackage.jsonがあるのが原因の模様。
release/appの方でもelectronをインストールすることで回避できた。

また、他の対処方法として、electron-builderのバージョンを下げるか、バージョンを固定で指定するとかもある模様。

なお、各種ライブラリのバージョンを戻したり、npmのキャッシュのクリアとか色々試したが関係なかった。

npm関連のクリアは `node_modules` を削除。
```pwsh
# キャッシュをクリア
npm cache clean --force
# 再インストール
npm i
```

```pwsh
node_modules/.bin/electron -v
v40.6.1
```
