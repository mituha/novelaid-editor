# リファクタリングメモ

バイブコーディングで書かせているため、あちこち問題がある場合の修正用のメモ。

## チャット表示の共通化

ユーザー入力部分も共通化。
推論有無やツール有無の設定を追加のため。


## 左右ペイン部分

LeftPane、RightPaneにpropsで渡しているのは内部で扱うパネルに依存している。
別な渡し方を検討する。

## ファイルパスの扱いの再確認

documentsのキーとなっているパスの扱いなど。
ある程度調整したが、まだ各所に処理が散らばっており、きちんと処理されていない。
現状、内部的には絶対パスで処理されている。
結局、これはこれで良いかも。

## エディター部分

トークナイザーやインテリセンスの登録部分をCodeEditorからファイルを分離してドキュメントの種類毎で管理できるようにする。
マークダウン編集の時に追加のインテリセンス等を使用したり、専用のトークナイザーを使用したりできるようにする。
マークダウンの場合にはルビ、傍点関連のみ追加で登録する。
また、現在、コンテキストメニューにルビや傍点関連のメニューがあるが、マークダウンと小説の時のみで良い。
css等の編集時には表示しない。
このように、ドキュメントの種類によって、個別のものや一部共通のものがあるため、それらを調整する。
