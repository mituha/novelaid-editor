# ライブラリ依存関係

ライブラリの依存関係で動作しなくなったこともあり、ライブラリの依存関係の確認方法等を記載します。

```pwsh
# 基本
npm list
# npmやnodeのチェック
npm doctor
# npm doctor でバージョンが低かった場合
# 最新の安定版に更新
npm install -g npm@latest
# 特定のバージョンを指定する場合
npm install -g npm@10.2.4

# nodeのバージョン更新用
nvm -v

```
nvmが未インストールの場合、インストール
https://github.com/coreybutler/nvm-windows/releases/latest

```pwsh
# nodeのバージョン確認
nvm list
# LTS
nvm install lts
nvm use lts
# 最新版
nvm install latest
nvm use latest
```

```pwsh
# アップデートが必要なパッケージの確認
npm outdated
# アップデート
npm update  
# セキュリティの確認
npm audit
# セキュリティの修正
npm audit fix
```

```pwsh
# 特定のパッケージの依存関係をチェック
npm list <パッケージ名>
# 特定のパッケージの依存関係をチェック
npm explain <パッケージ名>

# 重複しているパッケージを削除
npm dedupe

## パッケージのバージョン情報
npm info <パッケージ名> version

## 依存関係
npm view <パッケージ名> dependencies
```

package.jsonにoverridesを追加して強制使用

```json
{
  "overrides": {
    "package-name": "1.2.3"
  }
}
```

## txtlintのmicromarkのバージョン問題

最終的には下記overridesで解決
```json
{
  "overrides": {
    "remark-parse": "11.0.0",
    "micromark": "^4.0.2",
    "@textlint/markdown-to-ast": {
      "micromark": "~2.11.0",
      "remark-parse": "9.0.0",
      "remark-gfm": "1.0.0",
      "mdast-util-from-markdown": "^0.8.0"
    }
  }
}
```

症状としては、ReactMarkdownでの表示時に「`n`」を含む場合にエラーが発生する。
これは、実際にはmicromarkのバージョンが競合している事に起因していた。

```pwsh
novelaid-editor@0.42.5
├─┬ react-markdown@10.1.0
│ └─┬ remark-parse@11.0.0 overridden
│   └─┬ mdast-util-from-markdown@2.0.3
│     └── micromark@4.0.2
└─┬ textlint@15.5.2
  └─┬ @textlint/textlint-plugin-markdown@15.5.2
    └─┬ @textlint/markdown-to-ast@15.5.2
      ├─┬ mdast-util-gfm-autolink-literal@0.1.3
      │ └── micromark@2.11.4
      ├─┬ remark-footnotes@3.0.0
      │ ├─┬ mdast-util-footnote@0.1.7
      │ │ └── micromark@2.11.4
      │ └─┬ micromark-extension-footnote@0.3.2
      │   └── micromark@2.11.4
      ├─┬ remark-gfm@1.0.0 overridden
      │ └─┬ micromark-extension-gfm@0.3.3
      │   ├─┬ micromark-extension-gfm-autolink-literal@0.5.7
      │   │ └── micromark@2.11.4 deduped
      │   ├─┬ micromark-extension-gfm-strikethrough@0.6.5
      │   │ └── micromark@2.11.4 deduped
      │   ├─┬ micromark-extension-gfm-table@0.4.3
      │   │ └── micromark@2.11.4 deduped
      │   ├─┬ micromark-extension-gfm-task-list-item@0.3.3
      │   │ └── micromark@2.11.4 deduped
      │   └── micromark@2.11.4 deduped
      └─┬ remark-parse@9.0.0 overridden
        └─┬ mdast-util-from-markdown@0.8.5
          └── micromark@2.11.4 deduped
```
`textlint@15.5.2`の参照する`@textlint/textlint-plugin-markdown@15.5.2`経由のライブラリが古いためです。
実際には、textlintのmarkdownプラグインは使用しない想定。  
設定で明示的にオフには変更した。
また、overridesで対応した。

解決までの手順としては、

```pwsh
npm list
npm list micromark
npm view <パッケージ名> dependencies
```

等の繰り返しで地道に調査。
