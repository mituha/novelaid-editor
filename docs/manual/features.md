# できること

このソフトでできること、できないこと、ついでに、しないこと。  
このソフトは基本的に作者が実用と趣味で開発しているものです。そのため、できること、できないこと、しないことは作者の使用用途に依存しています。

なお、機能追加や修正の要望は広く受け付けています。
以下で`しないこと`として挙げている項目も、要望次第では変更される可能性があります。
また、このソフトでは`できないこと`や`しないこと`でも別なソフトを作成するかもしれません。

## できること

* WEB小説の執筆

### できてるかあやしいこと

作者が頻繁に使用していない機能については実装が怪しくなったり、完成していない可能性があります。  
なお、バイブコーディングによりAIにプログラム作業を行わせているため、頻繁にバグが交じる可能性があります。

## できないこと

現状できないこと、および、技術的に出来ないこと等。


## しないこと

* 時間、タスク管理
  + 別なソフトを使用してください

放っておくと再現なくソフトに機能を詰め込んでしまいかねないので自重してシンプルにする予定です。
